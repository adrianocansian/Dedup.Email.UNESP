# Política de Segurança

## Versões suportadas

Este repositório contém um script Google Apps Script para uso individual em contas Gmail da UNESP. Por ser um projeto de uso pontual e sem versionamento de releases ativo, a branch `main` é sempre a versão de referência.

## Reportando uma vulnerabilidade

**Não use Issues públicas para relatar vulnerabilidades de segurança.**

Caso identifique algum problema de segurança real ou potencial relacionado a este script, siga as orientações abaixo:

1. Envie um e-mail para **adriano.cansian@unesp.br** com o assunto `[SECURITY] Dedup.Email.UNESP`.
2. Descreva o problema com o máximo de detalhes possível:
   - Passos para reproduzir
   - Impacto esperado
   - Ambiente utilizado (navegador, conta Google, etc.)
3. Você receberá uma confirmação de recebimento em até **5 dias úteis**.
4. Uma estimativa de prazo para correção será fornecida quando aplicável.

## Escopo

Este repositório contém apenas um script Google Apps Script para uso em contas individuais de Gmail institucional da UNESP. Questões de segurança relacionadas à infraestrutura de e-mail da UNESP em si devem ser encaminhadas aos canais oficiais da universidade.

## Observação

Este projeto não coleta, armazena nem transmite dados pessoais a servidores externos. O script opera inteiramente dentro do ambiente Google Workspace do próprio usuário.
