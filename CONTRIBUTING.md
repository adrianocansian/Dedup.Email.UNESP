# Como contribuir

Obrigado pelo interesse em contribuir com o **Dedup.Email.UNESP**!

Este é um projeto acadêmico mantido pela UNESP. Contribuições externas são bem-vindas, desde que sigam as orientações abaixo.

## Reportando problemas (Issues)

- Use a aba **Issues** do repositório para reportar bugs ou sugerir melhorias.
- Verifique se o problema já foi reportado antes de abrir uma nova issue.
- Descreva o problema com clareza: o que aconteceu, o que era esperado e os passos para reproduzir.
- Inclua informações sobre o ambiente (conta Google, tipo de lista, etc.).

> **Atenção:** Para vulnerabilidades de segurança, não use Issues. Consulte o arquivo [SECURITY.md](SECURITY.md).

## Sugerindo melhorias via Pull Requests

1. Faça um **fork** do repositório.
2. Crie uma branch com um nome descritivo: `git checkout -b melhoria/nome-da-melhoria`.
3. Realize as alterações no código.
4. Certifique-se de que o script continua funcionando corretamente no Google Apps Script.
5. Faça o commit das alterações com uma mensagem clara: `git commit -m 'Descrição da melhoria'`.
6. Envie o Pull Request descrevendo as mudanças realizadas e o motivo.

## Padrões de código

- Escreva o código em inglês ou português, mantendo consistência com o estilo existente.
- Comente as funções e blocos de lógica relevantes.
- Evite dependências externas ao Google Apps Script.
